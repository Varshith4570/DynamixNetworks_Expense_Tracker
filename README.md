# 💰 Expense Tracker - GUI Application

A comprehensive Java Swing application for managing personal finances with an intuitive graphical interface.

![Java](https://img.shields.io/badge/Java-17%2B-blue)
![Swing](https://img.shields.io/badge/GUI-Swing-orange)
![License](https://img.shields.io/badge/License-MIT-green)

## 🌟 Features

- ✅ **Add & Track Transactions** - Record income and expenses with categories
- 📊 **Financial Reports** - Daily and monthly financial summaries
- 🔍 **Search & Filter** - Find transactions by category or keyword
- 💾 **Data Persistence** - Auto-save/load functionality
- 🎨 **Modern GUI** - User-friendly Swing interface
- 📈 **Real-time Summary** - Live income, expense, and balance tracking


## 🚀 Getting Started

### Prerequisites
- Java JDK 8 or higher
- Eclipse IDE (or any Java IDE)

### Installation

1. Clone the repository:
   https:/Varshith4570/github.com//DynamixNetworks_Expense_Tracker.git

2. Open in Eclipse:
   - File → Import → Existing Projects into Workspace
   - Select the cloned folder

3. Run the application:
   - Right-click `ExpenseTrackerGUI.java`
   - Run As → Java Application

## 📖 Usage

### Adding a Transaction
1. Click "➕ Add Transaction"
2. Enter date, type (Income/Expense), category, amount, and description
3. Click "💾 Save"

### Generating Reports
1. Click "📊 Generate Report"
2. Select report type (Daily/Monthly)
3. Enter the desired date/month
4. View detailed financial summary

### Searching Transactions
1. Click "🔍 Search"
2. Enter keyword
3. View filtered results
