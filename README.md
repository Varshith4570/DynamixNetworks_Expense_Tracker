# 💰 Expense Tracker - GUI Application

A comprehensive Java Swing application for managing personal finances with an intuitive graphical interface.

## 🌟 Features

- ✅ Add & Track Transactions (Income/Expense)
- 📊 Generate Daily and Monthly Reports
- 🔍 Search and Filter Transactions
- 💾 Auto-save Data Persistence
- 🎨 Modern Swing GUI Interface

## 🚀 How to Run

1. Clone this repository
2. Open in Eclipse IDE
3. Run `ExpenseTrackerGUI.java`

## 🔧 Technologies

- Java 8+
- Swing GUI
- Serialization for data storage
